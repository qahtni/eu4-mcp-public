GENERAL CONVENTIONS (all C)
1. SysV: this=rdi. CCountryTag (8 bytes) is passed BY VALUE in one register (rsi when 1st real arg). Player tag = CGameState::GetPlayer() const @0x13d174a (rdi=gs, tag in rax); gs=*(0x2fca490).
2. CFixedPoint (int32 x1000) is passed BY POINTER (invisible reference, not a register): CCountry::ChangeMaintenanceSliders(CFixedPoint,CFixedPoint)@0x102c216 loads `[rsi]`,`[rdx]`, stores them in stack temps and passes &temp to the CChangeMaintenanceCommand ctor (rdx,rcx). CCountryEconomyView::SetLandSlider(CFixedPoint)@0x1a54656 does cvtsi2ss [rsi]. So pass int32* (value 1000 = 1.0 = 100%). Returned CFixedPoint/CString use sret in rdi.
3. `CString const&` = pointer to a libstdc++ cxx11 std::string. `CEU3Date` = int. bool = byte in low reg. Enums (MonarchAbility, LeaderType, ...) = 32-bit ints.
4. Session: either *(gs+0x1dd0) idler, then call idler vptr+0x88 (GetSession, rax=CSession*) as every GUI site does, or CInGameIdler::GetSession() const @0x146e0a8. Idler vptr+0xa8 = GetPlayer (tag). CCountry also reaches it via (country+0x1870)->vptr+0x88. Tag of a CCountry* = [country+0x1c].
5. CCountry* from tag: db=*(0x2fc52f8); arr=[db+0xf8]; arr[(int16)(tag>>32)]. CProvince* from id: [gs+0x1c78] + id*0x2d20; province id = [prov+0x1c]; province owner tag = [prov+0x448] (qword).
6. Many ctors take PROVINCE POINTERS but store only the id ([prov+0x1c]); CCommand serialization turns pointers into ids/CIDs, so pass real, live pointers.
7. CRef<T> = {T* ptr; CID id (8 bytes)}; the CID of a CReferenceObject-derived object lives at [obj+0xc] (CAdvisor, CEvent, CRebelFaction, CMercenaryCompany: obj ptr = GetObjectFromID result); for CUnit [unit+0x34] (CUnit* = GetObjectFromID(CID const&)@0x1fea3e8 result - 0x28, null stays null); CLeader: result used as is.
8. Definition lookups (all C, this=instance object in rdi, CString const* in rsi, return ptr in rax or null; "Null" variants return a null-object, compare against it): see per-action lines. Templated commands (CCommandTemplate<...>) take args as const refs (ALL pointers) and the caller overwrites vptr=_ZTV<Class>+0x10 after the template ctor returns; members are stored in REVERSE arg order. Inlined (no ctor symbol) commands: base init = [+8]=0x165 (int), [+0xc]=0, CString::CString() at +0x10, [+0x30]=-1 (qword), [+0x38]=0 (u16), [+0x3c]=token (int), [+0x40]=0xffff (u16), [+0x44]=0, then fields, then vptr.
9. Only CMacroBuildInterface (build) and CMoveCommand call IsValid before Post; ProcessCommands calls IsValid again anyway (spec section a).
10. Many CCountry methods already build+post the command from a CCountry* (this) on the main thread: TakeBankLoan()@0xfe736a, PayLoan(CLoan*)@0x101aad6, PayAllLoans()@0x101b384, CancelLoan(CLoan*)@0x101ab3c, ExtendLoan(CLoan*)@0x101b31e, ChangeMaintenanceSliders(CFixedPoint*,CFixedPoint*)@0x102c216, ChangeColonialMaintenanceSlider@0x102c298, ChangeMissionaryMaintenanceSlider@0x102c304, Recruit(LeaderType,CString const&,bool)@0xff2548.
