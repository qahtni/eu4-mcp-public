 - CCountryTag = 8 bytes, passed/returned in one register: bytes0-2 ASCII tag, byte3 unused, int16 country index at bytes 4-5, byte7 = "valid" flag
   (CDiplomaticAction::IsSelectable@0x11b1882+0x11 returns false at once when action byte +0x13 or +0x23, i.e. byte7 of tag1/tag3, is 0). Build tags with
   CCountryDataBase::GetTag(char const*,bool)@0xf514c8 or copy country+0x1c; never hand-craft (CreateEmptyAction uses 0x2d2d2d="---" as null tag).
 - CEU3Date = int32 by value in a register (current date = gs+0x1da0; "null date" constant = 0x29c77f8). When the param is `CEU3Date const&` pass a pointer.

   Functions returning CFixedPoint/CString/CArray by value use sret in rdi. Functions below returning int (GetWarScore, GetWarScoreCost, WillAIAccept...) return in eax.
 - CString = std::__cxx11::string layout (0x20 bytes: ptr,len,cap/sso[16]); construct with CString::CString()@0x254b128 (_ZN7CStringC2Ev) or hook-side std::string.
